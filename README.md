# SQL 기반 지표 신뢰성 검증

과금 세그먼트 · 확률형 아이템 · 결제 데이터, 3개 축으로 매출 지표의 신뢰성을 검증한 프로젝트

## 파일구성

```
sql/
├── 01_data_quality/            -- 데이터 품질 체크
├── 02_segment_retention/        -- 세그먼트 분류 지표
├── 03_probability_verification/ -- 확률 지표
├── 04_payment_anomaly/          -- 결제 지표
└── 05_summary/                  -- 종합 & 액션플랜
data/          -- PostgreSQL 적재용 CSV 8종
schema.sql      -- DDL
```

## 분석흐름

```
문제정의: 매출 숫자를 믿을 수 있는가 — 세그먼트/확률/결제 3개 축으로 검증

Part1: 데이터 품질 체크
└── 결측치·참조무결성·이상치·중복·날짜범위·논리정합성 전수 검사 → 이상없음

    ↓

Part2: 세그먼트 분류 지표
├── 매출 상위20% 유저가 전체매출의 82.9% 차지 (파레토)
├── 상위권 내부 활동일수 편차 큼 (표준편차 45.3일) → 세그먼트 균일성 의심
└── 결제액×반복구매빈도 재분류 시 4주차 잔존율 76.4% vs 38.8%
    → 결제액 단일기준 대신 결제액×빈도 조합으로 재정의 필요

    ↓

Part3: 확률 지표
├── 한정배너 확정지급(천장) 구간 분리 → 평균값 착시 제거
└── 확정지급 전까지 실제확률이 지속적으로 공시확률(2.0%)보다 낮음 (1.61~1.75%), 전체뽑기의 99.9%가 해당 구간
    → 확정지급 이전 구간 확률 공시 로직 재점검 필요

    ↓

Part4: 결제 지표
├── 환불률 상위10%(383명)만 46.5%, 나머지 0%대
├── 기기당 계정 6개 집중된 이상계정군 300명 발견 (환불률 49.1%)
└── 이상계정군 결제시각 100% 새벽2~5시 집중 (독립신호로 재확인)
    → 조직적 계정 운용 정황, 매출 분리·모니터링 강화 필요

    ↓

Part5: 종합
└── 총매출 21.3억 → 순매출 16.8억 (78.5%), 세그먼트 혼입률 12.8% 확인
    → 3개 액션플랜 우선순위 도출
```

## 사용기술

- **DB**: PostgreSQL, DBeaver
- **SQL 기법**: 윈도우 함수(NTILE, LAG), CTE 체이닝, 상관/EXISTS 서브쿼리, VIEW, FILTER 절 조건부 집계
- **데이터**: AI를 활용해 생성한 합성 데이터 (유저 10,000명, 관측기간 180일, 8개 테이블)

---

## Part 2. 세그먼트 분류 지표

**발견**
- 매출 상위 20% 유저가 전체 매출의 **82.9%**를 차지
- 그 내부에서 활동일수 편차가 큼 (평균 107.2일, 표준편차 45.3일) → 같은 "고과금 유저" 안에 성격이 다른 유저가 섞여 있다는 신호
- 고과금 유저(결제액 상위5%)를 반복구매빈도로 재분류 시 4주차 잔존율 **76.4% vs 38.8%**로 약 2배 차이
- 확률형 구매비중이 높을수록 결제액 변동성도 커짐 (4분위 12,609원 → 223,832원)
- 단, 변동성이 클수록 오히려 잔존율이 소폭 높음 → 변동성은 이탈위험이 아닌 결제 규모 지표로 재해석

**결론**
> 고과금 유저 세그먼트는 결제액(1차 필터) × 반복구매빈도(2차 세분화) 조합 기준으로 재정의해야 한다.

## Part 3. 확률 지표

**발견**
- 한정 배너는 천장(pity) 도달 시 100% 확정지급 — 이 구간을 분리하지 않으면 착시 발생
- 확정지급 전까지는 계속해서 실제확률이 공시확률(2.0%)보다 낮게 유지됨 (천장 전 1.61% / 천장 임박 1.75%)
- 전체 뽑기의 99.9% 이상이 이 확정지급 전 구간에서 발생 — 유저가 실제로 경험하는 뽑기 대부분이 이 낮은 확률 구간에 해당
- 한정 배너 6종 전체에서 동일 패턴 재현
- 상시 배너는 공시확률과 일치 — 문제없음

**결론**
> 유저가 실제로 경험하는 확률은 광고된 수치보다 명백히 낮다. 확정지급 이전 구간의 확률 공시 로직을 재점검해야 한다.

## Part 4. 결제 지표

**발견**
- 계정별 환불률 상위 10%(383명)만 평균 46.5%, 나머지는 0%에 가까움
- 기기 연결 관계 확인 → 50개 기기에 계정이 정확히 6개씩(총 300명) 집중, 나머지는 전부 1기기=1계정
- 이 300명의 평균 환불률 **49.1%** (정상계정 3.8%의 약 13배)
- 이 300명의 결제 시각은 **100%가 새벽 2~5시**에만 발생 (정상계정은 저녁 19~23시 중심으로 하루 전체 분포)
- 기기 집중·시간대 집중, 독립된 두 신호가 같은 결론을 가리킴

**결론**
> 이 300개 계정은 개별 이상치가 아니라 조직적으로 운용되는 계정군이다. 매출 집계에서 별도 분리하고, 결제수단 검증과 새벽 시간대 모니터링을 강화해야 한다.

## Part 5. 종합

Part 2~4에서 확인한 왜곡을 매출로 환산:

| 단계 | 금액 | 총매출 대비 |
|---|---|---|
| 총매출 | 21억 3,533만원 | 100% |
| (-) 환불 | 2억 6,762만원 | 12.5% |
| (-) 이상계정 잔여매출 | 1억 9,067만원 | 8.9% |
| **최종 순매출** | **16억 7,704만원** | **78.5%** |

총매출 기준 고과금 유저(상위5%, 500명) 중 **64명(12.8%)**은 순매출 기준 재계산 시 상위5%에서 탈락한다. 세그먼트 판단 자체가 매출 왜곡의 영향을 받고 있었다는 뜻이다.
